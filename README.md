## 🚀 Project Overview

The PhonePe Data Analytics Dashboard is a data visualization project developed using Microsoft Power BI to transform digital payment data into meaningful visual insights.

The project focuses on exploring payment-related metrics, identifying patterns, and presenting analytical information through an interactive dashboard.

*The PhonePe analytics dashboard developed using Microsoft Power BI.*

## 🎯 Project Objectives

- 📈 Analyze PhonePe-related digital payment data.
- 🧹 Prepare and organize data for analysis.
- 📊 Develop KPI visualizations and interactive reports.
- 🔍 Explore transaction trends and comparisons supported by the dataset.
- 💡 Communicate analytical findings through visual storytelling.

## ✨ Key Features

- 📊 Interactive dashboard and supported filters.
- 📌 KPI cards for important metrics.
- 📈 Transaction trend analysis, where available.
- 🌍 Geographic and category-level comparisons, where supported.
- 💡 Data-driven insights through clear visualizations.

## 🛠️ Technology Stack
